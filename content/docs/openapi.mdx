The OpenPhonex API ships a live **OpenAPI 3** document. It is the machine-readable
source of truth for every REST endpoint, request/response schema, and auth
requirement — generated from the running service, so it never drifts from the
docs.

## Open the spec

<Cards>
  <Card title="/control-plane/openapi.json" href="/control-plane/openapi.json" description="The live OpenAPI 3 document, served by the API." />
</Cards>

Point any OpenAPI-aware client at it — Swagger UI, Postman, an SDK generator, or
an agent that reads OpenAPI directly. The same scoped `tai_` Bearer key
authenticates every operation.

<Callout title="Two agent-readable surfaces">
  `/control-plane/openapi.json` is the **API** surface. The
  [Agent surface](/docs/llms) pages describe the **docs/blog** corpus — this
  site's `/llms.txt`, `/llms-full.txt`, and the `.md` on every page. An agent
  can pull both to get the full picture.
</Callout>
