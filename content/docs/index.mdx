Skysay is **agent-native telephony**: real phone numbers, calls, and SMS
that an AI agent can run on its own. Because every capability is exposed over
**MCP** and described in **llms.txt**, any MCP-capable agent already knows how to
use it — no bespoke integration required.

<Callout title="Already speak MCP?">
  You are basically done. Point your client at `POST /mcp`, pass a scoped key as
  a Bearer token, and the Skysay tools show up in `tools/list`.
</Callout>

## What is Skysay?

Skysay gives your agents the phone side of the world: search number
coverage, wire an agent to a number, place an authorized outbound call, read
recordings and transcripts, and send SMS — all behind one scoped API key that is
also your permission boundary. Numbers, compliance, billing, and provider
operations stay on the Skysay side; your agent gets the capability tools and
nothing else.

## Quickstart

Connect an MCP client and inspect coverage without placing a phone call. This
uses the OpenClaw connector; any MCP client follows the same shape. To hear a
configured agent, use a [browser test](/docs/trial-calls). PAYG has no monthly
platform subscription; [browser credit and purchased funds](/docs/billing)
are separate balances.

<Steps>

<Step>

### Install the connector

Drop the Skysay skill into your agent and register the MCP server it ships
with.

```bash
# copy the connector into your agent checkout
cp -R connectors/openclaw skills/skysay

# register the hosted MCP endpoint (mcporter)
npx mcporter add skysay --url https://api.skysay.ai/mcp
```

</Step>

<Step>

### Mint a scoped key

One org key with agent-facing scopes only. Control-plane scopes are omitted and
clamped server-side, so the key cannot self-escalate.

```bash
curl -X POST "$SKYSAY_BASE_URL/v1/api-keys" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d '{"name":"my agent",
       "scopes":["account:read","coverage:read","agents:write",
                 "calls:read",
                 "recordings:read"]}'
# -> returns a tai_… key ONCE. Store it now.
```

</Step>

<Step>

### Your agent calls the tools

Set the key in the MCP server env, restart, and ask your agent in plain
language. It picks the right tool from `tools/list`.

```text
you › show my account and search GB number coverage; do not place a call

# the agent runs, over MCP:
→ account_overview(...)
→ get_coverage(country="GB")
✓ workspace balance and coverage summarized back to you
```

</Step>

</Steps>

<Callout type="info" title="Safety by default">
  Live outbound calls and SMS are policy-gated: the agent evaluates
  `evaluate_outbound_policy` and surfaces the decision and cost before anything
  leaves the machine. Scopes fail closed.
</Callout>
