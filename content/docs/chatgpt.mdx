ChatGPT can work in your Skysay workspace: read your calls, set up AI agents
and, when you allow it, place calls and send SMS. Skysay is published in
ChatGPT's plugin directory, so you install it there and sign in to Skysay. You
do not create or paste an API key.

ChatGPT operates Skysay for you. It is not the voice on the call: the person on
the phone hears your AI agent. To make a system you run the voice on calls, see
[Wire an agent to a number](/docs/wire-an-agent).

For OpenAI's coding agent, use the [Codex guide](/docs/codex).

## Install the plugin

<Steps>
<Step>

**Open the Skysay plugin in ChatGPT.** Go to
[Skysay in ChatGPT's plugin directory](https://chatgpt.com/plugins/plugin_asdk_app_6ac1ceaf15cc8191bbebd2b6aca503c4),
or open **Settings → Plugins** in ChatGPT and search for Skysay.

</Step>
<Step>

**Choose Install plugin.** ChatGPT asks you to connect your Skysay account.

</Step>
<Step>

**Sign in to Skysay.** ChatGPT opens Skysay in your browser. Sign in with the
account that belongs to the workspace you want to connect. You can also create
an account at this step.

</Step>
<Step>

**Choose what ChatGPT may do.** The consent screen names the app that is asking
and the workspace, and lists each permission as a checkbox. Untick anything you
do not want ChatGPT to do, then choose **Allow access**, or **Deny** to stop.

</Step>
</Steps>

## Check that it works

Ask ChatGPT:

```text
Show my Skysay workspace overview.
```

A new workspace returns empty lists. Installing the plugin does not create an
AI agent or a phone number.

## What ChatGPT can do

What is ticked when you choose **Allow access** is exactly what ChatGPT gets.
Check the list before you allow it: it can include changing AI agents, placing
calls and sending SMS. Reading transcripts, recordings and SMS text has its own
permissions. See
[Permissions, consent and reconnecting](/docs/mcp#permissions-consent-and-reconnecting)
for the full list and [Scopes & permissions](/docs/scopes) for what each one
allows.

The plugin uses Skysay's
[OpenAI connector](/docs/mcp#openai-connector-calling-without-wallet-top-ups) at
`https://api.skysay.ai/mcp/openai`. It can place calls, but it cannot add funds
to your wallet: you top up in the Skysay workspace.

Installing the plugin does not by itself approve payments, number purchases or
billable calls: you approve each paid call, SMS or number. Read
[Billing](/docs/billing) before you ask ChatGPT to do something that costs
money.

## Disconnect ChatGPT

Open **Connected apps** on the [API keys](https://skysay.ai/api-keys) page in
the Skysay workspace and revoke the connection. It stops working at once. Then
remove the plugin in ChatGPT under **Settings → Plugins**. API keys are
separate and are revoked on their own.

## If something goes wrong

| What you see | What to do |
| --- | --- |
| The consent screen shows the wrong workspace | Choose **Deny**, sign out of Skysay in that browser, and connect again with the right account. |
| ChatGPT says a tool is forbidden or needs more consent | The connection lacks that permission. Disconnect, install the plugin again and leave the permission ticked on the consent screen. |
| ChatGPT asks you to sign in again | The connection expired. Sign in again; your workspace is unchanged. |
